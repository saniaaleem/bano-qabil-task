Will my website work on mobile?

Yes. The layout adapts to mobile phones, tablets and larger screens.

Can I customize the website?

Yes. You can change the text, colors, services, project cards and packages in the source files.

Does the contact form send messages?

This starter version validates the form in your browser. To deliver messages, connect a secure backend or form service.

Can I publish it online?

Yes. You can deploy the static files to GitHub Pages, Netlify or another static hosting provider.
